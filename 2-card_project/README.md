# Card Design Project

A simple React card design project that displays employee profile cards with image, name, role, skills, rating, earned amount, and hourly rate.

## What I did
- Created a reusable `Card` component
- Passed employee data from `main.jsx` to `App.jsx` and then to `Card.jsx`
- Displayed profile details using props
- Styled the card with CSS
- Used `.map()` to render multiple cards from an array

## What I used
- React
- JSX
- Props
- `.map()`
- CSS
- Lucide React icon

## What I learned
- How to pass data between components
- How props work in React
- How to render repeated UI from an array
- How to style a card layout
- How to fix blank screen issues caused by missing props
